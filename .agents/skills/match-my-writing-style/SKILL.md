# Match My Writing Style

1. Use direct, active phrasing, short-to-medium punchy sentences, and natural contractions.
2. Avoid corporate buzzwords ("synergistic", "holistic", "leverage", "utilize") and self-congratulatory filler.
3. Match the target channel register (concise technical notes, direct terminal output, or structured executive work orders).
